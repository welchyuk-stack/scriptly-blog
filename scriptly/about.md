# About Scriptly

Scriptly makes Mac automation accessible to everyone.

## The Problem

Repetitive Mac tasks waste hours every week:
- Organizing emails
- Renaming files in bulk
- Moving downloads to folders
- Syncing data between apps

Most automation tools require coding. We're solving that.

## The Solution

**Describe what you want. Scriptly writes the AppleScript.**

Using on-device Apple Intelligence, Scriptly generates working scripts from plain-English descriptions — nothing leaves your Mac.
