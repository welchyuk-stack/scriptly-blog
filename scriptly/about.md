# About Scriptly

Scriptly makes Mac automation accessible to everyone.

## The Problem

Repetitive Mac tasks waste hours every week:
- Organizing emails
- Renaming files in bulk
- Moving downloads to folders
- Syncing data between apps

Most automation tools require coding. We're solving that.

## The Solution

**Pick a template, fill in a few fields, and run it.**

Scriptly is an AppleScript automation app for Mac (macOS 14+) with 115 ready-to-run templates. Pick one — or just describe what you want — fill in a few simple fields such as a folder, an email address or a time, then run it, copy it or schedule it to run automatically.

On Macs with Apple Intelligence, Scriptly's AI runs entirely on-device: describe a task in plain English and Scriptly finds and fills in the right template, Explain turns any script into a plain-English summary, and Fix diagnoses a failed script and suggests a correction. Nothing runs until you press Run or set a schedule, and scripts that could change or delete files ask for confirmation first.

### Features

- ✓ 115 ready-to-run templates across Files, Email, Calendar, Slack, GitHub, Notion, Zoom, spreadsheets, text, apps, display, audio, network and more
- ✓ On-device AI on Macs with Apple Intelligence — describe a task and Scriptly finds and fills in the right template; Explain summarises any script; Fix diagnoses a failed script and suggests a correction
- ✓ Scheduled automations — daily, weekly or once; runs on time while Scriptly is open, and a lightweight background helper catches up if it isn't
- ✓ Menu bar quick-run — star your favourites and run them in one click, or hide Scriptly from the menu bar
- ✓ Community Marketplace — save your own templates, share them and download others'; every shared script is scanned for risky commands, and you can report a template or block an author
- ✓ Scripts that could change or delete files ask for confirmation first; step-by-step setup instructions for every automation
- ✓ Save custom templates and browse your run history
- ✓ Keyboard shortcuts (⌘N New Template, ⇧⌘G Generate with AI, ⌘[ Back), VoiceOver support, dark mode and local time formats
