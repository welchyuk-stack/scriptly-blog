# Scriptly Support

Need help with Scriptly? Here's how to reach us.

## Contact

Email [appscriptly@gmail.com](mailto:appscriptly@gmail.com) with any questions, bug reports, or feature requests. We read every email and aim to reply within a couple of days.

## Common questions

**AI script generation or repair isn't working.**
Both features run entirely on-device using Apple Intelligence, which requires an Apple Intelligence-capable Mac (Apple silicon, with Apple Intelligence enabled in System Settings → Apple Intelligence & Siri) running a supported macOS version. On a Mac that doesn't support Apple Intelligence, the AI features won't be available — templates, menu bar quick-run, and scheduled automations all work regardless, since only the AI generation and repair steps depend on it.

**A template's generated script won't run.**
Scriptly copies AppleScript to your clipboard; it doesn't run scripts itself. Paste it into Apple's Script Editor (or your saved location for menu bar quick-run) and run it from there. If a script generated by the AI has an error, Scriptly's repair step should catch most issues automatically before you see it — if one still gets through, email us the template or prompt that produced it and we'll take a look.

**A script needs folder access I didn't expect.**
Scriptly is sandboxed by macOS. The only file access it ever requests is to a folder you explicitly choose via a standard "Choose Folder" dialog — it can't reach anywhere on your Mac you haven't picked yourself.

**The Marketplace won't load, or I can't publish a template.**
The Marketplace requires being signed in to iCloud on your Mac — check System Settings → [your name] → iCloud. Both browsing and publishing need that sign-in, since the Marketplace is built on Apple's CloudKit.

**I found a template in the Marketplace that's broken, inappropriate, or spam.**
Use the report option on the template's detail screen. Reporting locks the template from public view immediately and flags it for review — you don't need to contact us separately unless you want to add context.

**Where are my favourites and saved templates stored?**
Locally on your Mac, using the standard macOS preferences system. They're not synced anywhere and are removed if you delete the app.
