# Windows Keyboard Shortcuts vs Mac

The single biggest source of Windows-switcher frustration isn't a missing feature — it's `Ctrl` where your finger expects it to be `⌘`. Almost every shortcut you know still exists on Mac. It's just one key over.

## The one rule that covers 80% of shortcuts

On Windows, `Ctrl` is the modifier for nearly everything: copy, paste, save, undo, find. On Mac, `⌘` (Command) — the key with the little pretzel-looking icon, right next to the spacebar — takes over that exact job.

So the mental swap is almost mechanical:

| You'd press on Windows | Press this on Mac instead |
|---|---|
| `Ctrl+C` | `⌘+C` |
| `Ctrl+V` | `⌘+V` |
| `Ctrl+Z` | `⌘+Z` |
| `Ctrl+S` | `⌘+S` |
| `Ctrl+F` | `⌘+F` |

`Ctrl` on a Mac keyboard isn't unused — it does different jobs (mostly Unix-y, terminal-flavored things), but it's rarely the copy/paste modifier you're used to reaching for.

## Where it stops being a simple swap

A handful of shortcuts don't map cleanly, and these are the ones that actually trip people up:

**App switching.** Windows uses `Alt+Tab` to cycle both apps and windows within an app. Mac splits this: `⌘+Tab` cycles *apps*, and `⌘+\`` (the key above Tab) cycles *windows within the current app*. If you're `⌘+Tab`-ing looking for a second Finder window, it won't show up — that's what the backtick shortcut is for.

**Closing vs quitting.** This one causes real confusion. On Windows, closing a window's last instance usually quits the app. On Mac, `⌘+W` closes the window, but the app keeps running in the background — you'll still see its icon bouncing in the Dock, or a dot underneath it. To actually quit, you need `⌘+Q`. If your Mac feels like it's "full of apps you didn't open," this is almost always why.

**Delete does something different in text fields.** Windows' `Delete` key removes the character ahead of the cursor (forward delete). On most Mac keyboards, the key labeled `Delete` behaves like Windows' `Backspace` — it deletes backward. Forward-delete exists (`Fn+Delete` on a laptop), it's just not the default behavior of the key you'd expect.

**Frozen app? Different combo entirely.** `Ctrl+Alt+Delete` doesn't exist on Mac. The equivalent is `⌘+⌥+Esc`, which opens Force Quit — a much smaller, calmer window than Windows' Task Manager, listing just your open apps.

## A few Mac-native shortcuts worth learning on day one

These don't have a clean Windows equivalent, but they'll save you real time:

- `⌘+Space` — Spotlight search. Launch any app, do quick math, or find a file without touching the Dock or Finder.
- `⌘+Shift+4` — Screenshot a selected area (drag to select, releases automatically saves to Desktop).
- `⌘+,` — Opens Preferences/Settings for almost any app that's currently active. Universal shortcut, works almost everywhere.

## How to actually retrain your fingers

Don't try to memorize a list — that's what reference pages are for (bookmark this one: [full Windows → Mac keyboard shortcut reference](/windows-to-mac/keyboard-shortcuts/), searchable and printable). What actually works is picking the five shortcuts you use most on Windows, writing them on a sticky note with their Mac equivalents, and sticking it to your monitor for a week. Muscle memory rewires faster than you'd think — most people report it feeling automatic within 10–14 days.

The good news: once `Ctrl` becomes `⌘` in your head, almost everything else follows the same pattern. It's one habit to break, not fifty.
