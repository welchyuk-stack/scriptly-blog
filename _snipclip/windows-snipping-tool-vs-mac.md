# Windows Snipping Tool vs Mac: Every Screenshot & Markup Option Compared

If you're switching from Windows, Snipping Tool (or its successor, Snip & Sketch, now merged back into one app in Windows 11) is probably your mental model for "how screenshots work": one app, capture and markup together. macOS splits that job differently — not worse, just split up — and there's more than one way to close the gap depending on what you need.

## How does Windows Snipping Tool actually work?

Snipping Tool on Windows 11 handles capture (rectangular, freeform, window, or full-screen — `Win+Shift+S` to launch it) and opens directly into a markup-ready view afterward: pen, highlighter, and a ruler tool are right there in the same window, no second app needed. Capture and annotate feel like one continuous action because they're one app.

## What does macOS do instead?

`⌘+Shift+4` (or `⌘+Shift+5` for more options) handles capture — see the [full shortcut breakdown](/snipclip/mac-screenshot-shortcuts/) for exact behavior. Markup, if you want it, lives in Preview — a separate app, reached either by catching the screenshot thumbnail before it auto-dismisses, or manually opening the saved file afterward. The tools themselves are comparable; they're just not merged into one continuous flow by default.

## Which one should you actually use?

**If you only need what Snipping Tool gave you** — one hotkey, capture, mark up, share, done, nothing else — **SnipClip** is the closest match and the cheapest paid option: a single $1.99 purchase with no ongoing cost, built specifically around that one workflow rather than trying to do everything.

**If you also want scrolling capture or OCR and don't mind a slightly heavier app**, **Shottr** is free to use indefinitely (with occasional prompts to buy a license) and covers more ground — scrolling screenshots, text recognition, a color picker, and basic cloud upload.

**If you need team features — shareable links, custom-domain branding, SSO — or you're capturing constantly and want unlimited cloud storage**, **CleanShot X** is built for that, at a correspondingly higher price: $35 one-time for the basic app-plus-cloud tier, or a $10–12/month subscription for the Pro tier with unlimited storage and team management.

**If you're happy with the built-in tools**, macOS's `⌘+Shift+4` and Preview's Markup cost nothing extra and cover full-screen, window, and area capture with a real (if separate) annotation toolbar — see [how to annotate a screenshot on Mac](/snipclip/annotate-screenshot-mac/) for the exact steps.

## The honest takeaway

None of these is objectively "best" — they solve different amounts of the same problem. If your Windows habit was "Snipping Tool handles the whole thing in one window" and that's genuinely all you need, SnipClip rebuilds exactly that habit for $1.99 with nothing else to configure. If you find yourself wanting more — a searchable capture history, scrolling pages, OCR — that's the signal to look at Shottr or CleanShot X instead, since SnipClip deliberately doesn't try to be those tools.
